# Инструкция по настройке и запуску

## Требования

- Windows 10/11
- Python 3.8+ (установлен и добавлен в PATH)
- Доступ к интернету (VPN должен быть отключён)

---

## Шаг 1. Установка зависимостей

Откройте командную строку (Win + R → `cmd` → Enter) и выполните:

```cmd
pip install google-auth google-auth-httplib2 google-api-python-client
```

---

## Шаг 2. Настройка Yandex Cloud

1. Зайдите в [console.yandex.cloud](https://console.yandex.cloud)
2. Создайте сервисный аккаунт с ролью `search-api.webSearch.user`
3. В разделе **API-ключи** создайте новый ключ
4. Запишите значение ключа — он показывается только один раз
5. Запишите **folderId** вашего каталога (видно в URL консоли или в настройках каталога)

---

## Шаг 3. Настройка Google Sheets

1. Зайдите в [console.cloud.google.com](https://console.cloud.google.com)
2. Создайте проект или выберите существующий
3. Включите **Google Sheets API**: APIs & Services → Enable APIs → Google Sheets API → Enable
4. Создайте сервисный аккаунт: APIs & Services → Credentials → Create Credentials → Service Account
5. Скачайте JSON-ключ: нажмите на аккаунт → Keys → Add Key → JSON
6. Переименуйте скачанный файл в `wordstat-google.json`
7. Откройте вашу Google Таблицу → Поделиться → добавьте email сервисного аккаунта с правами **Редактора**

---

## Шаг 4. Размещение файлов

Положите в одну папку (например `C:\Users\User\Downloads`):
- `wordstat_fill.py`
- `wordstat-google.json`

---

## Шаг 5. Запуск

Откройте командную строку в папке с файлами и выполните:

```cmd
python wordstat_fill.py --apikey ВАШ_API_КЛЮЧ --folder ВАШ_FOLDER_ID
```

Скрипт выведет прогресс:

---

## Повторный запуск

Если скрипт прервался (ошибка сети, лимит запросов) — просто запустите его снова той же командой. Уже собранные недели будут пропущены.

---

## Добавление новых ключевиков

1. Откройте нужную вкладку в Google Таблице
2. Добавьте новый ключевик в первую строку (в любой свободный столбец после существующих)
3. Запустите скрипт — он автоматически подхватит новые ключевики и соберёт по ним данные

---

## Частые ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `TimeoutError` | VPN блокирует соединение | Отключите VPN |
| `HTTP 401` | Неверный API-ключ | Создайте новый ключ в Yandex Cloud |
| `HTTP 429` | Превышен лимит 100 запросов/час | Подождите час и запустите снова |
| `HTTP 500` | Данные за период недоступны | Яндекс обновляет данные с задержкой 2-3 недели |
| `HttpError 403` | Google Sheets API не включён | Включите API в Google Cloud Console |
| `ConnectionAbortedError` | Обрыв соединения с Google | Скрипт повторит попытку автоматически |

---

## Настройка периода сбора

По умолчанию собираются данные с 05.01.2026 по 26.04.2026. Чтобы изменить период, отредактируйте строку в коде:

```python
WEEKS = _generate_weeks(date(2026, 1, 5), date(2026, 4, 26))
```

- Никогда не публикуйте `wordstat-google.json` в открытом репозитории
- Если ключ был случайно опубликован — немедленно пересоздайте его в Google Cloud Console
- Файл `.gitignore` уже исключает `wordstat-google.json` из git
