## Ключевые договорённости

- Вся бизнес-логика — в `services/`, роуты только принимают запросы и возвращают ответы
- Миграции — только через Alembic, не менять схему руками
- Секреты — через `.env`, в репозиторий не коммитим
- Ветки: `main` — стабильная, `dev` — рабочая, фичи — `feature/название`
- PR обязателен перед мержем в `main`, даже если работает один человек
