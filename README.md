# Wordstat Monitoring

Автоматический сбор статистики поисковых запросов из Яндекс Wordstat с записью данных в Google Таблицу.

## Возможности

- Сбор частотности запросов по неделям через Yandex Search API (Wordstat)
- Поддержка нескольких вкладок — каждая вкладка соответствует отдельному бренду/теме
- Ключевики читаются из первой строки каждой вкладки автоматически
- Столбец ИТОГО с суммой показов за неделю
- Сохранение после каждой недели — данные не теряются при обрыве соединения
- При повторном запуске пропускает уже заполненные недели
- Гео-фильтр по Тюменской области

## Быстрый старт

```bash
pip install google-auth google-auth-httplib2 google-api-python-client
python wordstat_fill.py --apikey ВАШ_КЛЮЧ --folder ВАШ_FOLDER_ID
```

## Структура таблицы

Каждая вкладка должна содержать ключевики в строке 1 начиная со столбца B. Столбец A используется для меток недель.

```
      | A                      | B           | C        | D     |
------|------------------------|-------------|----------|-------|
  1   |                        | жк айрис    | айрис жк | ИТОГО |
  2   | 05.01.2026-11.01.2026  | 150         | 80       | 230   |
  3   | 12.01.2026-18.01.2026  | 120         | 95       | 215   |
```
